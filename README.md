# ATM Emulator

Эмулятор банкомата (АТМ) для учебного задания: хранит банкноты по ячейкам (по номиналам), принимает пополнение, выдаёт запрошенную сумму (жадно, от большего номинала к меньшему) или сообщает об ошибке, если сумму выдать нельзя.

## Требования к окружению
- **JDK 17+** (для `List.of(...)`).  
- IDE (IntelliJ IDEA / Eclipse) или консольная сборка через `javac/java`.

Проверка, что JDK доступен в терминале:

```bash
java -version
javac -version
```

## Структура проекта
- `src/atm/` — ядро доменной логики АТМ
  - `Atm` — контракт операций
  - `AtmImpl` — реализация с ячейками и жадной выдачей
  - `CashCell` — ячейка банкнот конкретного номинала
  - `Denomination` — фиксированный набор номиналов
  - `CannotDispenseException`, `InvalidDepositException` — ошибки
- `src/Main.java` — небольшой smoke-тест с `assert`

## Публичный API
Интерфейс `atm.Atm`:
- `deposit(Map<Denomination,Integer> banknotes)` — пополнение
- `withdraw(int amount)` → `Map<Denomination,Integer>` — выдача набора банкнот или `CannotDispenseException`
- `balance()` → `long` — текущий остаток в АТМ

## Как работает выдача
Выдача — **жадная**:
- перебираем номиналы **от большего к меньшему**
- на каждом номинале берём `min(available, remaining / denomValue)`
- если после прохода остаток `remaining != 0` — выдача невозможна

Важное свойство: операция **атомарная** — если сумму выдать нельзя, состояние АТМ не меняется.

## Запуск
Из корня проекта:

```powershell
javac -d out src\Main.java src\atm\*.java
java -ea -cp out Main
```

Флаг `-ea` включает `assert`-проверки в `Main`.

## Пример использования (код)
Смотрите `src/Main.java`: там показано пополнение, успешная выдача и кейс, когда выдача невозможна (и баланс не меняется).
